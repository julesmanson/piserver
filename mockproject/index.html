    START / STOP SERVER

    START 1. Double-click piserver.py — opens its own window
    2. Terminal: python piserver.py — keep terminal open
    3. PowerShell own window:
    Start-Process python -ArgumentList "piserver.py" -WorkingDirectory "..."
    4. PowerShell silent background:
    Start-Process pythonw -ArgumentList "piserver.py" -WorkingDirectory "..." -WindowStyle Hidden STOP Double-click again (toggle) · Close server window · Ctrl+C in terminal
